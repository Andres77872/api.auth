## Help me in [patreon](https://patreon.com/findit_moe)

This is free, but the server is not.

The system is very efficient, but i have the modules project in several servers,
some in America and another in Europe, and by that the latency between servers
is around 150-300 ms (America - Europe), but the search can be done in less than 30ms for a
database with more than 22 million of images with 32 results per search. The
result count has a huge impact on the search time.

A huge portion of time is spent on the latency servers, if it is possible for me,
in the future ill make a CDN for the image provider and databases, but it is
too expensive because it needs around 120gb RAM for the database.
